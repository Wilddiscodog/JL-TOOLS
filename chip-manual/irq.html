CHAPTER 4

中断系统

pi32v2 内核 64 源中断控制器：中断号总表、优先级、向量注册与 ISR 编写规范。

中断模型

pi32v2 内核支持 64 个中断源（向量表基址 IRQ_MEM_ADDR = 0x2BF00）， 每个源可注册回调并指定优先级。SDK 封装了注册/开关接口，驱动里中断服务函数用 ___interrupt 属性修饰。

hwi.h 中每个中断号后的注释（0/1/2）为 SDK 建议的优先级档位： 数字越大优先级越高，蓝牙时序相关（27/28/30/38）建议保持 2 级。

使用方法

#include "asm/hwi.h"
#include "asm/irq.h"

/* 1. 注册中断：优先级 0-3，cpu_id 固定填 0 */
static ___interrupt void my_spi2_isr(void)
{
    if (JL_SPI2->CON & BIT(4)) {        /* pending? */
        /* ... 读取数据 ... */
        spi_clear_pending(SPI2);
    }
}

request_irq(IRQ_SPI2_IDX, 1, my_spi2_isr, 0);

/* 2. 开关中断（掩码操作） */
irq_disable(IRQ_SPI2_IDX);
irq_enable(IRQ_SPI2_IDX);

/* 3. 卸载 */
unrequest_irq(IRQ_SPI2_IDX);

/* 4. 临界区（关闭全局中断） */
local_irq_disable();
/* ... */
local_irq_enable();
ISR 中不得调用阻塞 API（如 fopen/printf 长打印）；与主循环共享数据用 local_irq_disable() 保护或做成环形缓冲。SDK 的 UART/SPI 中断收发已封装好，一般无需自写 ISR。
