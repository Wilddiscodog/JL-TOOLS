杰理 pi32v2 音频 SoC —— 依据 SDK 头文件逆向整理的寄存器级参考手册：涵盖时钟、GPIO、串口、SPI/I²C、定时器、PWM、ADC、音频、USB、SD 卡、Flash 控制器、电源管理与安全加速器。

芯片简介

AC6956C（SDK 内部平台代号 BR23）是杰理科技的蓝牙音频 SoC，内核为杰理自主的 pi32v2 32 位 DSP（头文件中亦称 q32DSP），面向蓝牙音箱、学习机、故事机等音频产品。 本手册全部内容依据 SDK 头文件（include_lib/driver/cpu/br23/asm/ 等）逆向整理， 寄存器地址与位域均可从 SDK 源码复核。

主要特性：

  • 片内 NOR Flash 直接代码执行（XIP），支持 1/2/4 线模式与 eFuse 密钥加密启动
  • 五路 PLL 输出（480/320/192/137/107 MHz），HSB/LSB/SFC 独立分频
  • 3×UART、3×SPI、1×硬件 I²C、4×32 位定时器、8 通道 MCPWM
  • 全差分 SARADC（16 通道含 PMU/音频内部通道），硬件 Audio DAC/ADC + FIFO
  • USB Full-Speed 设备控制器（5 组端点，SDK 内置 HID/CDC/MSC/AUDIO 类驱动）
  • 双 SD/MMC 控制器（TF 卡）、RTC/PWR 掉电域（P33）、硬件 CRC16/AES
命名说明：SDK 中 JL_XXX 宏为各外设寄存器结构体指针， 定义于 asm/br23.h（总线外设）与 asm/csfr.h（内核 SFR）。 寄存器统一按 32 位访问——结构体中 __u8/__u16 均被宏替换为 unsigned int。

系统架构框图

图 1-1 AC6956C 总线架构与外设概览（虚线 = 总线连接）

系统由两条内部总线组成：HSB 高速总线（基址 0x1F0000）挂接 SFC、PSRAM、 音频加速器等高带宽模块；LSB 低速总线（基址 0x1E0000）挂接全部常规外设。 内核 SFR（中断控制、MMU、调试模块等）位于 0x100000 起始的独立空间，定义见 csfr.h。

外设地址映射

寄存器基址计算公式：base = 段基址 + (64×grp + adr) × 4 （map_adr 宏，grp 0x00-0xFF、adr 0x00-0x3F，组间距 256 字节）。
