CHAPTER 13

SD / TF 卡控制器

双 SD/MMC 主机：命令/数据通路、卡检测与 DMA——对应 JL_SD0/SD1（0x1E1400 / 0x1E1500）。

概述

双 SD/MMC 控制器（SD0 / SD1），支持 SD 卡 1/4 位模式。SDK 的文件系统 （挂载为 storage/sd0 / storage/sd1 设备）构建其上。 本机 TF 卡接在 SD1（PC3-PC5 引脚组），电子书、字库均存于 TF。

图 13-1 SD/MMC 控制器

寄存器（JL_SD0 @ 0x1E1400，SD1 @ 0x1E1500）

偏移寄存器属性说明
0x00CON0RW主控制
0x04CON1RW时钟分频/电气
0x08CON2RW状态/中断
0x0CCPTRWO命令指针（写入发送命令）
0x10DPTRWO数据指针（写入启动数据传输）
0x14CTU_CONRW超时控制
0x18CTU_CNTWO超时计数
平台数据中 .sfr = (volatile u16 *)JL_SD1——SD 控制器部分寄存器按 16 位访问，与全芯片 32 位访问的惯例不同，移植驱动时注意。

使用方法

#include "asm/sdmmc.h"

/* 板级配置（本机 TF = SD1） */
SD1_PLATFORM_DATA_BEGIN(sd1_data);
    .port                   = 'C',          /* PC3-PC5 */
    .priority               = 3,
    .max_freq               = 25000000,
SD1_PLATFORM_END();

/* 电源与挂载（SDK 设备层自动完成） */
sd_set_power(1);                          /* TF 供电轨 */
dev_manager_online_check_by_logo("sd1", 0);  /* 在线检查 */

/* 文件系统访问（fscan/fopen 见 fs.h） */
eb_scan = fscan("storage/sd1/C/EBOOK/", "-tTXT -sn", 1);
TF 供电与按键梯共用 POW_FLS 电源轨（PB11）——sd_set_power/sdpg_config 会接管该轨，初始化顺序：先按键采样、后挂 TF。
