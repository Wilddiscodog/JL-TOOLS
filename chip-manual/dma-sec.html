CHAPTER 16

DMA 与安全加速器

系统 DMA、硬件 CRC16、AES-GCM、真随机数与外设流加密——对应 JL_DMA / CRC / AES / RAND / PERIENC / DCP。

系统 DMA（JL_DMA @ 0x1E3F00）

总线级 DMA 控制器，各外设（UART/SPI/SD/AUDIO…）的 DMA 请求经它仲裁。 多数场景由外设自身的 DMA 描述符完成（如 UART 环形缓冲），此控制器用于 存储器间搬运配置。

偏移寄存器属性说明
0x00PRI0-3RW通道优先级
0x20MSGRW消息/触发
0x24MSG_CHRO（读）当前通道
0x28RDL / RDHRW读地址低/高
0x30WRL / WRHRW写地址低/高

CRC16 加速（JL_CRC @ 0x1E3500）

硬件 CRC16 计算：向 FIFO 连续写入数据，结果存于 REG。SDK 封装为 CRC16(ptr, len)，用于镜像校验（打包产物头部 CRC）与通信校验。

偏移寄存器属性说明
0x00FIFOWO数据入口（写即计算）
0x04REGRWCRC 结果 / 初值
#include "asm/crc16.h"
u16 c = CRC16(buf, len);                 /* 一步计算 */
u16 c2 = CRC16_with_initval(buf, len, 0xFFFF);
spi_crc16_set(init);                     /* 手动预置（连续分段计算） */
u16 v = spi_crc16_get();

AES 加速（JL_AES @ 0x1E4300）

AES 引擎，寄存器含 NONCE/HEADER/TAGLEN/TAGRES——支持 AES-GCM （带认证标签）及常规模式，源/目的地址为总线 DMA。蓝牙加密与固件校验使用。

偏移寄存器属性说明
0x00CONRW模式/启动
0x04DATINRW输入数据
0x08KEYWO密钥
0x0CENCRES0-3RW结果寄存器
0x1CNONCEWOGCM nonce
0x20HEADERWOGCM AAD
0x24SRCADR / DSTADRWODMA 源/目的
0x2CCTCNTWO计数
0x30TAGLENWO标签长度
0x34TAGRES0-3RO认证标签结果

真随机数 / 外设流加密

  • JL_RAND @ 0x1E3B00：R64L/R64H（RO）读出 64 位真随机数，蓝牙地址/密钥熵源。
  • JL_PERIENC @ 0x1E4100：SPI0/SD0 数据流加密（ENCCON/ENCKEY/ENCADR），TF 卡加密读写场景。
  • JL_DCP @ 0x1F1300（HSB）：数据拷贝加速器（CON/ADR，IRQ 48），大块 memcpy 卸载。
这些加速器 SDK 都有高层封装（crc16.h / crypto 库），仅在极限优化时才需要寄存器级操作；AES-GCM 的密钥调度请信任 SDK 实现。
