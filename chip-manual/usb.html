CHAPTER 12

USB 设备控制器

Full-Speed 设备 + OTG：SIE/PHY 控制、5 组端点 DMA 与 UTMI 索引寄存器——对应 JL_USB（0x1E1800）、JL_USB_IO（0x1E5100）。

概述

USB Full-Speed 设备控制器（12 Mbps）+ OTG 检测：1 个控制端点 EP0 + 4 组双向数据端点。FIFO 大小按类配置（SDK 默认：EP0/HID/MSD 64B、CDC 128B、 AUDIO 256B）。设备控制器包含一套 UTMI 风格的索引寄存器 （FADDR/INDEX/TXCSR…），经 CON1 的主机访问接口读写。

CON0 位名（usb.h，JL_USB @ 0x1E1800）

位域名称说明
[0]PHY_ONPHY 上电
[1]LOW_SPEED低速模式
[2]USB_NRSTIP 复位
[4]CIDOTG 角色
[5]VBUS（读）VBUS 状态
[9]PDCHKDPDP 检测使能
[10]SOFIESOF 中断使能
[11]SIEIESIE 中断使能
[12]CLR_SOF_PND清 SOF pending
[13]SOF_PND（读）SOF 标志
[14]SIE_PND（读）SIE 标志
[15]CHKDPODP 检查
[17:16]DP_SE / DM_SEDP/DM 单端检测

UTMI 索引寄存器（经 INDEX 选择端点）

偏移寄存器说明
0x00FADDR设备地址
0x01POWER电源/挂起/复位
0x02-0x0BINTRTX/RX/USB 及使能中断状态与使能
0x0CFRAME1/2帧号
0x0EINDEX选择当前端点
0x0FDEVCTL设备控制
0x10-0x1BTXMAXP/CSR/RXMAXP/CSR/COUNT/TYPE/INTERVAL端点配置与状态

使用方法

/* SDK 场景化封装（通常无需碰寄存器） */
#include "device/usb/otg.h"

/* OTG 数据（board 板级） */
struct otg_dev_data otg_data = {
    .usb_dev_en = 1,             /* 作 USB 设备 */
};

/* 本机实践：日志模式下置 usb_dev_en=0，
   OTG 检测被禁用，DP/DM 保持 UART0 功能 */
otg_data.usb_dev_en = 0;

/* MSD 升级通道：接电脑后 UDISK 模式被 JlFlash 用于烧录 */
DP/DM 同时是 UART0 调试口的引脚——USB 枚举期间控制台会失效；需要全程日志时必须禁用 OTG（见上）。
