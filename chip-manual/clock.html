CHAPTER 2

时钟系统（CLK / PLL）

振荡源选择、PLL 五路输出、HSB/LSB/SFC 总线分频与外设时钟多路选择——对应 JL_CLOCK 寄存器组（0x1E0000）。

时钟树

AC6956C 的时钟体系为 振荡源 → PLL → 总线分频 → 外设时钟 四级结构。 系统主时钟可由 RC、BTOSC（12-26 MHz 晶振）、RTOSCL 或 PLL 提供（CLK_CON0[8:6]）， SDK 默认使用 BTOSC×PLL 方案；本项目配置为 PLL480M ÷ 2 = 240 MHz （TCFG_CLOCK_SYS_HZ）。

图 2-1 时钟树与外设时钟选择
SDK 屏蔽了寄存器细节：应用层用 clk_early_init() / clk_set() / sys_clk_set()（clock.h）。直接改寄存器前务必先注册 CLOCK_CRITICAL_HANDLE_REG 临界区回调，否则频率切换会撕裂蓝牙时序。

寄存器总表（JL_CLOCK @ 0x1E0000）

偏移寄存器属性说明
0x00PWR_CONRW电源控制（SDK 上电默认配置，勿动）
0x04HTC_CONRWHTC 控制
0x08SYS_DIVRWHSB/LSB/SFC 分频
0x0CCLK_CON0RW主时钟源选择、RC 振荡、时钟输出
0x10CLK_CON1RW外设时钟源选择（USB/AUDIO/UART/BT…）
0x14CLK_CON2RWPLL 系统时钟选择与分频
0x18CLK_CON3RW内核复位控制（SDK 保留）
0x40PLL_CONRWPLL 主控制
0x44PLL_CON1RWPLL 分频/输出使能/LDO
0x48PLL_INTFRWPLL 接口
0x4CPLL_DMAXRWPLL 分频上限
0x50PLL_DMINRWPLL 分频下限
0x54PLL_DSTPRWPLL 分频步进

CLK_CON0（0x0C）主时钟控制

位域名称说明
[0]RC_EN内部 RC 振荡使能
[1]RCH_ENRC 高频选择：0=250K，1=16M
[3:2]TEST_SEL测试时钟选择：0=主时钟，1=PAT
[5:4]OSC_CLOCK_IN0=BTOSC，1=XOSC_FSCK，2=RTOSCL，3=PAT
[8:6]MAIN_CLOCK_SEL主时钟：0=RC，4=BTOSC，6=RTOSCL，7=PLL
[9]SFR_MODESFR 时钟：0=随空闲停，1=常开
[12:10]PA0_CLOCK_OUTPA0 时钟输出选择
[15:13]PB8_CLOCK_OUTPB8 时钟输出选择

CLK_CON1（0x10）外设时钟源

位域名称说明
[1:0]USB_CLOCK_INUSB：0=PLL48M，1=OSC，2=LSB，3=禁止
[3:2]AUDIO_CLOCK_IN音频：0=PLL48M，1=OSC，2=LSB，3=禁止
[6:4]GPCNT_CLOCK_IN通用计数器时钟源
[11:10]UART_CLOCK_INUART：0=PLL48M，1=OSC，2=LSB，3=禁止
[15:14]BT_CLOCK_IN蓝牙：0=PLL48M，1=HSB，2=LSB，3=禁止
[17]SFC_SCKESFC 时钟停使能
[19:18]WL2ADC_CLOCK_IN0=PLL96M，1=HSB，2=LSB，3=禁止
[22:21]WL2DAC_CLOCK_IN同上
[29:28]SFC_CLOCK_DELAYSFC 时钟延迟
串口/USB 的 PLL48M 是 PLL 的固定 48 MHz 分支，不随系统主频变化——波特率因此稳定，即使系统降频运行。

CLK_CON2（0x14）系统时钟与分频

位域名称说明
[1:0]PLL_SYS_SEL0=192M，1=137M，2=320M，3=480M
[5:2]PLL_SYS_DIV系统分频（编码见下）
[6]PLL_ALNK_ENALNK 时钟使能
[7]PLL_ALNK_SEL0=192M/17，1=480M/39
[13:12]PLL_FM_SELFM 时钟：0=192M，1=137M，2=107M，3=禁止
[17:14]PLL_FM_DIVFM 分频
[30]DPLL_UDENDPLL 更新使能

PLL_SYS_DIV 编码（与 SDK 枚举一致）：0→÷1，1→÷3，2→÷5，3→÷7；4-7→÷(1/3/5/7)×2；8-11→÷(1/3/5/7)×4；12-15→÷(1/3/5/7)×8。240 MHz = 480M 选 ÷1×2（编码 4）。

SYS_DIV（0x08）总线分频

位域名称说明
[7:0]HSB_CLK_DIVHSB 分频（0 = 直通；240M 配置在此）
[10:8]LSB_CLK_DIVLSB 分频
[14:12]SFC_CLK_DIVSFC 分频

PLL_CON（0x40）/ PLL_CON1（0x44）

位域名称说明
CON[0]PLL_ENPLL 使能
CON[1]PLL_RESTPLL 复位
CON[8:2]PLL_DIVnPLL 分频系数 n
CON[9]PLL_REF_SEL参考时钟：0=BTOSC，1=RCLK
CON[17:16]PLL_RSEL参考选择
CON[23:22]PLL_PFDPFD 电流
CON[26:24]PLL_ICP电荷泵电流
CON1[11:0]PLL_FBDS反馈分频 DS
CON1[14:12]PLL_IVCOVCO 电流
CON1[23:22]PLL_DIVn_EN0=×2，1=直通，2=使能 2-33 分频
CON1[24-28]CLK nM_OE480/320/192/137/107M 各路输出使能
CON1[30]PLL_DAC_OEDAC 专用时钟输出使能

使用方法

#include "asm/clock.h"

/* 1. SDK 标准流程：板级配置声明系统主频（board_config.h） */
#define TCFG_CLOCK_SYS_HZ   240000000     /* PLL480M / 2 */
#define TCFG_CLOCK_OSC_HZ   24000000      /* BTOSC 晶振频率 */

/* 2. 运行时降频（如进省电模式）：24M / 48M 两档 */
sys_clk_set(SYS_24M);
sys_clk_set(SYS_48M);

/* 3. 常用 API（asm/clock.h） */
clk_get("sys");                          /* 查询当前频率 */
clk_set("lsb", 8000000);                 /* 设定外设总线频率 */
clock_dump();                            /* 打印时钟树状态（调试） */
clock_set_sfc_max_freq(40000000, 80000000);

/* 4. 把时钟引到引脚观察（测量主频/PLL） */
PA0_CLOCK_OUT(PA0_CLOCK_OUT_HSB);        /* PA0 输出 HSB 时钟 */
PB8_CLOCK_OUT(PB8_CLOCK_OUT_PLL320);     /* PB8 输出 PLL320M */
本机（AC6956C8）实测：240 MHz 已是 PLL480M÷2 的规格上限，不要尝试 480M 直驱（超规格不可启动）。
