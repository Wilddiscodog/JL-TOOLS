CHAPTER 10

ADC 采样

16 通道全差分 SARADC：外部引脚、PMU/音频内部通道、轮询采样表与独占模式——对应 JL_ADC（0x1E3100）。

概述

全差分 SARADC，16 个输入通道：14 个外部引脚复用 + RTC + 内部 MUX （PMU 电压/温度、音频偏置、PLL/FM/BT 监测）。SDK 驱动维护一张最多 10 通道的 轮询采样表——调用 adc_add_sample_ch() 后硬件循环采样， adc_get_value() 取最近值，适合按键分压、电池电压等低频场景； 需要精确单次测量用 adc_enter_occupy_mode() 独占模式。

寄存器（JL_ADC @ 0x1E3100）

偏移寄存器属性说明
0x00CONRW采样控制（通道选择/启动，SDK 驱动管理）
0x04RESRO采样结果（原始码值）
控制位细节在闭源驱动内；结果需经 VBG 基准换算：电压 = adc_value_to_voltage(vbg, val)，SDK 自动用 PMU 带隙基准校准。

使用方法

#include "asm/adc_api.h"

/* 1. 加入轮询表（内部会启动 ADC 循环采样） */
adc_add_sample_ch(AD_CH_PB1);        /* AD 按键 */
adc_add_sample_ch(AD_CH_VBAT);       /* 电池电压 */

/* 2. 读取原始值 / 换算电压 */
u32 raw = adc_get_value(AD_CH_PB1);
u32 mv  = adc_get_voltage(AD_CH_VBAT);

/* 3. 精确单次测量（独占模式，测完释放） */
adc_enter_occupy_mode(AD_CH_VDC13);
u32 v = adc_get_occupy_value();
adc_exit_occupy_mode();

/* 4. 电压换算辅助（用 VBG 基准校准） */
u32 volt = adc_value_to_voltage(adc_get_value(AD_CH_PMU_VBG), raw);
本机实践：AD 按键梯（PB1）上电采样前必须先拉高电源轨 PB11（POW_FLS），并确认 adc_add_sample_ch(AD_CH_PB1) 已注册——否则 adc_get_value 恒为 0。
