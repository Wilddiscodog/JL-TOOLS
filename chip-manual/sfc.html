CHAPTER 14

SPI Flash 控制器

片内 1MB NOR 的 XIP 控制器：1/2/4 线命令、SFCENC 加密与 eFuse 校验、VM 持久区——对应 JL_SFC（0x1F0200）/ JL_SFCENC（0x1F0300）。

概述

SFC（Serial Flash Controller）管理 片内 1MB NOR Flash，CPU 经 XIP 直接执行代码（所以代码区只读，运行数据在 RAM/VM）。支持 1/2/4 线命令、 可配四线最高频率（clock_set_sfc_max_freq()），并有 SFCENC 加密单元：按 eFuse ChipKey 对指定地址区加解密——出厂镜像若密钥不符则无法启动。

使用方法

#include "asm/spiflash.h"
#include "asm/sfc_norflash_api.h"

/* SDK 已把片内 flash 封装为设备，读写以"页/扇区"为单位 */
spi_flash_dev_read(addr, buf, len);       /* 读 */
spi_flash_dev_erase_sector(sector);       /* 擦 4KB（写入前必须擦） */
spi_flash_dev_write(addr, buf, len);      /* 写 */

/* 频率上限（四线 100MHz 需 flash 支持） */
clock_set_sfc_max_freq(40000000, 80000000);

/* VM 持久存储（掉电保存） */
#include "syscfg_id.h"
syscfg_write(CFG_EBOOK_SHELF, &data, sizeof(data));
syscfg_read(CFG_EBOOK_SHELF, &data, sizeof(data));
代码区 XIP 只读；任何扇区擦写期间会挂起总线（卡顿数十 ms），实时性敏感路径（音频 ISR）避免触发 flash 写。VM 写入同样如此——阅读器每次翻页写一次 VM 是可接受的频率。
加密启动：镜像由 isd_download 以 -key 密钥流加密，芯片 eFuse 校验 ChipKey（本机 0xB165）。经实测，离线打包（Device offline）阶段产物与密钥文件无关，烧录失败应先排查 uboot/电源而非盲目换 key。
