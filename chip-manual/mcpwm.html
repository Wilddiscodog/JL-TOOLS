CHAPTER 9

MCPWM 多通道 PWM

6 时基 × 8 比较通道的 PWM 发生器：边沿/中心对齐、互补死区、H/L 双输出与通道重映射——对应 JL_MCPWM（0x1E3000）。

概述

MCPWM 是独立的 多通道 PWM 发生器：6 个时基定时器 × 8 个比较通道， 每通道 H/L 两路输出，支持边沿/中心对齐与互补（带死区）模式， 用于背光调光、电机驱动、呼吸灯等。寄存器在 JL_MCPWM @ 0x1E3000， SDK 提供 struct pwm_platform_data 描述式配置。

寄存器布局（0x1E3000，按 32 位访问）

偏移寄存器属性说明
0x00TMR0_CON/CNT/PRRW时基 0：控制/计数/周期（3×4B）
0x0CTMR1_CON/CNT/PRRW时基 1
0x18TMR2 - TMR5RW时基 2-5（各 0x0C）
0x5CFPIN_CONRW故障/外部引脚控制
0x60CH0_CON0/CON1/CMPH/CMPLRW通道 0：控制、比较高/低
0x70CH1 - CH7RW通道 1-7（各 0x10）
0xF0MCPWM_CON0RW全局控制

pwm_platform_data 配置项

字段说明
frequencyPWM 频率（该时基统一）
pwm_ch_num通道 pwm_ch0-ch5
pwm_timer_num时基 pwm_timer0-5
duty占空比 0-10000（对应 0-100%）
pwm_aligned_modepwm_edge_aligned 边沿 / pwm_center_aligned 中心
h_pin / l_pin通道高低引脚；-1 表示不接硬件引脚
h/l_pin_output_ch_num非硬件引脚时占用的 GPIO 输出通道号（0-2）
complementary_en1=H/L 同相，0=互补（带死区）

使用方法

#include "asm/mcpwm.h"

struct pwm_platform_data pwm0 = {
    .frequency        = 1000,            /* 1kHz */
    .pwm_ch_num       = pwm_ch0,
    .pwm_timer_num    = pwm_timer0,
    .duty             = 5000,            /* 50% */
    .pwm_aligned_mode = pwm_edge_aligned,
    .h_pin            = IO_PORTB_04,     /* 硬件 H 引脚 */
    .l_pin            = -1,
    .complementary_en = 1,
};
/* 设备层注册后由 dev->init 生效（SDK 驱动枚举 MCPWM 设备） */

/* 运行时改占空比：直接写比较寄存器 */
JL_MCPWM->CH0_CMPL = new_duty;
注意通道枚举 pwm_ch_max = 6 与硬件 8 通道（CH0-7）的差异：SDK 设备层仅暴露 6 通道；CH6/CH7 可经寄存器直接使用。
