CHAPTER 11

音频系统

Audio DAC/ADC DMA-FIFO、模拟增益链（DAA/ADA）与 ALNK 数字音频接口——对应 JL_AUDIO（0x1E2F00）、JL_ANA（0x1E1900）。

概述

音频子系统由三部分组成：JL_AUDIO（DAC/ADC 的 DMA FIFO 与数字滤波）、 JL_ANA 中的 DAA/ADA 模拟寄存器组（增益/静音/偏置）、以及 ALNK0/1 数字音频链路（I²S/PCM，接外挂 codec）。 本机外挂 AXS2005B 功放（PB0 控制静音），DAC 输出经板级模拟通路接功放。

模拟部分在 JL_ANA @ 0x1E1900：DAA_CON0-7（0xC0 起，DAC 模拟：增益/静音/上电）、ADA_CON0-4（0xE0 起，MIC 偏置/增益），位定义由 SDK 电源/音频驱动（p33.h 宏、audio_adc.h）封装。

数字音频接口 ALNK0/1

JL_ALNK0 @ 0x1E2E00、JL_ALNK1 @ 0x1E3300：I²S/PCM 主从收发（CON0-3 + 4 组 DMA 描述符 ADR0-3 + LEN），时钟来自 PLL_ALNK（192M/17 或 480M/39 ≈ 11.29/12.31 MHz，对应 44.1/48k 族）。接外挂 codec 或蓝牙音频协处理器时使用；SDK 用 iis.h API 封装。

使用方法

/* 应用层走 SDK 框架（cpu/br23/audio_*.h），不直接碰寄存器 */
#include "asm/audio_adc.h"
#include "audio_dac.h"

/* 本机功放静音链（learning_board.c 实例）：
   音频活动回调 -> PB0 拉高使能 AXS2005B，空闲自动静音省电 */
learning_amp_mute(1);              /* 上电先静音 */
audio_dac_start(...);              /* 框架启动 DAC 通路 */

/* 采集 MIC（ADC 通路） */
audio_mic_ldo_en(0, &adc_data);    /* 本机关闭 MIC LDO 隔离声反馈 */
DAC 模拟上电顺序敏感（DAA 上电→放音→下电），务必通过 SDK 音频框架启停；直接写 ANA 寄存器可能出现爆音甚至损伤喇叭。
