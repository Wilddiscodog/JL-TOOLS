CHAPTER 15

电源管理（PMU / P33）

双电源域架构：VDDIOM/VDDIOW 电压档、P33 掉电域、LVD 复位、充电管理与软关机——对应 JL_P33（0x1E3E00）与 P3_* 寄存器组。

电源域

芯片分两个电源域：正常域（CPU/外设，由 VDDIOM/VDDIOW 供电，可配置 强弱两档：本机 VDDIOM=3.4V、VDDIOW=3.2V，经 P3_ANA_CON5）与 P33 掉电域（RTC、LRC 32K、唤醒检测、充电管理，独立供电，软关机后唯一存活的域）。 两域经 JL_P33 的 SPI 接口通信。

寄存器

偏移寄存器属性说明
0x00P33 PMU_CONRWPMU 接口控制（JL_P33 @ 0x1E3E00）
0x04P33 RTC_CONRWRTC 控制
0x08P33 SPI_CONRWP33 串行接口控制（含片选 BIT0/BIT8）
0x0CP33 SPI_DATRWP33 数据读写

P33 域内部寄存器经 SPI 接口按地址访问（p33.h），常用：

P33 地址名称说明
0x00-0x09P3_ANA_CON0-9模拟配置（IO 电压档位 CON5 等）
0x0C/0x0DP3_L5V_CON0/1LDO5V 控制（充电输入）
0x0EP3_SDPG_CONSD/TF 供电轨（POWER FET）
0x0FP3_FSPG_CONFlash/屏供电轨（POW_FLS）
0x10P3_PLVD_CONPLL/LDO 欠压检测
0x11P3_VLVD_CONVDDIOW 欠压检测（VLVD 档位：4=2.3V 复位阈值）
0x12P3_RST_SRC（读）复位来源
0x13/0x14P3_LRC_CON0/1LRC 32K 振荡控制
0x18/0x19P3_CHG_WKUP/READ充电唤醒与状态
P33 访问必须用 p33_cs_h()/p33_cs_l 临界区宏包裹（内部关中断防撕裂），SDK 提供 P33_TX_NBIT / P33_OR / P33_AND / P33_XOR 及 P33_CON_GET 完整原语。

充电管理（charge.h）

参数范围
充满电压3.869V - 4.567V（16 档，CHARGE_FULL_V_xxx）

使用方法

#include "asm/power/p33.h"
#include "asm/power_interface.h"

/* 软关机（掉电式：P33 域保留，等按键/RTC 唤醒 = 完整重启） */
power_set_soft_poweroff();

/* 复位来源（调试上电原因） */
u8 power_reset_source_dump();

/* 低功耗（睡眠）由系统框架按 idle 自动调度 */
struct low_power_param param = { ... };
power_init(&param);

/* 电压监测 */
u8 pct = get_vbat_percent();        /* 电量百分比（状态栏用） */
本机实测：软关机再开机 = 完整重启（非休眠恢复）；uboot 的按键采样每次开机都会执行。欠压阈值 VLVD 档位在 isd_config.ini 里配置（VLVD=4 → 2.3V），过低会导致锂电末段频繁复位。
