CHAPTER 6

SPI 总线

3 组 SPI 主/从控制器：单字节轮询、DMA 批量传输、1/2/4 线模式——对应 JL_SPI0-2（0x1E1C00 起）。

概述

内置 3 组 SPI（SPI0/1/2，寄存器相同）。SPI0 额外支持 2/4 位半双工模式 （配合 SFC 可外接四线 NOR）。CS/CLK/DI/DO 引脚有 4 组备选映射，经 spi_platform_data 的 port 字段选择。本机 SPI2 复用作 ST7305 屏幕与 W25Q128 外挂 Flash 总线。

寄存器（JL_SPI0 @ 0x1E1C00，SPI1/2 = +0x100 / +0x200）

偏移寄存器属性说明
0x00CONRW使能/主从/模式/中断/pending（驱动管理）
0x04BAUDWO波特率分频，spi_set_baud() 计算
0x08BUFRW单字节收发数据
0x0CADRWODMA 缓冲地址
0x10CNTWODMA 传输长度（写入即启动）
控制位细节封装在闭源驱动里；应用层走 spi.h 的完整 API（开盒即用，含 ISR 版本）。

线模式

枚举含义适用
SPI_MODE_BIDIR_1BIT全双工，DI 收 / DO 发常规外设
SPI_MODE_UNIDIR_1BIT半双工，DO 分时收发屏/Flash
SPI_MODE_UNIDIR_2BITDI+DO 双位分时仅 SPI0
SPI_MODE_UNIDIR_4BITDI+DO+D2+D3 四位分时仅 SPI0

使用方法

#include "asm/spi.h"

/* 板级：引脚组与速率（例：SPI2 用于屏 + 外挂 Flash） */
const struct spi_platform_data spi2_p_data = {
    .port = 'A',                    /* 引脚组选择 */
    .mode = SPI_MODE_BIDIR_1BIT,
    .role = SPI_ROLE_MASTER,
    .clk  = 24000000,
};

spi_open(SPI2);                     /* 打开 */
spi_set_baud(SPI2, 12000000);       /* 运行中改速率 */

/* 轮询单字节 */
spi_send_byte(SPI2, 0x9F);
u8 id = spi_recv_byte(SPI2, &err);

/* DMA 批量（屏刷场景） */
spi_dma_send(SPI2, framebuffer, len);

/* ISR 内使用专用接口（不可睡眠） */
spi_send_byte_for_isr(SPI2, b);
spi_dma_set_addr_for_isr(SPI2, buf, len, 1);
多设备共享同一 SPI 总线时（如本机屏 + W25Q128 共用 SPI2），各设备 CS 独立控制，传输前务必确认总线速率兼容；spi_open 会重配引脚与波特率。
