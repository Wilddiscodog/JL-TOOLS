CHAPTER 3

GPIO 与 IO 复用

4 组 56 个 GPIO：方向/上下拉/驱动能力寄存器、数字输入使能、IOMAP 输出通道路由、ADC 模拟复用与唤醒——对应 JL_PORTA-D / IOMAP / WAKEUP。

GPIO 模型

AC6956C 提供 PA0-PA15 / PB0-PB15 / PC0-PC15 / PD0-PD7 共 56 个 GPIO， 4 个端口组寄存器连续排列（每组 0x40 字节），每一位对应一个引脚。

图 3-1 端口寄存器模型（每位对应一个引脚）
输入缓冲由 DIE 位单独控制（数字输入使能）；读 IN 前必须置 DIE=1。 模拟功能（ADC/触摸）引脚需 DIE=0 以降低数字干扰。

寄存器（JL_PORTA @ 0x1E5000，B/C/D 依次 +0x40）

偏移寄存器属性说明
0x00OUTRW输出数据。DIR=1 时引脚电平 = OUT 位
0x04INRO输入数据（需先置 DIE）
0x08DIRRW方向：1=输出，0=输入
0x0CDIERW数字输入使能
0x10PURW内部上拉使能
0x14PDRW内部下拉使能
0x18HD0RW驱动能力 0 档
0x1CHDRW驱动能力（大电流档）
0x20DIEHRW输入使能扩展（高速档）

IO 复用与输出通道映射

外设信号到引脚没有传统"复用选择器"，而是通过 IOMAP 输出通道路由： 内部信号（UART TX、PWM、时钟输出等）进入 CH0/CH1/CH2 三个输出通道（各 16 选 1）， 再绑定到任意被使能为输出的引脚。

时钟输出可直接经 CLK_CON0 固定路由到 PA0 与 PB8（见时钟章节）。

使用方法

#include "asm/gpio.h"

/* 输出：POW_FLS 按键电源轨（本机实例） */
gpio_direction_output(IO_PORTB_11, 1);      /* 方向输出 + 输出 1 */

/* 输入 + 上拉（AD 按键） */
gpio_set_direction(IO_PORTB_01, 0);         /* 0 = 输入 */
gpio_set_pull_up(IO_PORTB_01, 1);           /* 22K 上拉（外部） */
gpio_set_die(IO_PORTB_01, 1);               /* 打开数字输入（读 IN 必需） */
int v = gpio_read(IO_PORTB_01);

/* 直接写端口寄存器（位操作） */
JL_PORTB->OUT |=  BIT(11);   /* PB11 = 1 */
JL_PORTB->OUT &= ~BIT(11);   /* PB11 = 0 */
JL_PORTB->DIR |=  BIT(11);   /* 输出 */

/* 关闭引脚（低功耗：浮空并关输入缓冲） */
gpio_close_uart0();          /* 释放调试串口引脚 */
引脚编号宏为 IO_PORTx_NN = 16×组 + 序号，因此 API 里的 u32 gpio 可直接做数组下标换算。

唤醒与中断

引脚电平变化经 JL_WAKEUP（0x1E5108，CON0-CON3）产生 IRQ_PORT_IDX（中断号 13）端口中断；软关机后由 P33 域的独立唤醒检测支持按键开机。SDK 的按键驱动（AD 键/IO 键/触摸）都构建在该机制之上。
