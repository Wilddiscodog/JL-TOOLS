CHAPTER 5

UART 串口

3 路异步串口：硬件环形 DMA 接收、DMA 发送、红外模式——对应 JL_UART0-2（0x1E2000 起）。

概述

AC6956C 内置 3 路异步串口（UART0/1/2，寄存器结构相同），特点是接收方向为 硬件环形 DMA 缓冲：CPU 只需查询 HRXCNT 硬件接收计数即可无丢包地 收取流式数据，非常适合调试控制台与外接模块通信。发送方向支持单字节（BUF）与 DMA 描述符（TXADR/TXCNT）两种方式。

寄存器（JL_UART0 @ 0x1E2000，UART1/2 = +0x100 / +0x200）

偏移寄存器属性说明
0x00CON0RW控制 0（使能/模式，SDK 驱动管理）
0x04CON1RW控制 1（红外/IR 模式等）
0x08BAUDWO波特率分频（驱动按时钟源自动计算）
0x0CBUFRW发送/接收数据字节（轮询模式）
0x10OTCNTRW输出触发计数
0x14TXADRRW发送 DMA 缓冲地址
0x18TXCNTWO发送字节数（写入即启动 DMA 发送）
0x1CRXSADRRW接收环形缓冲起始地址
0x20RXEADRRW接收环形缓冲结束地址
0x24RXCNTRW接收控制
0x28HRXCNTRO硬件接收计数（读取后自动清零）
SDK 未公开 CON0/CON1 的逐位定义（在闭源驱动库内），应用层应通过 uart_init() / 设备层 API 配置，不要直接写控制位。

使用方法

#include "asm/uart.h"

/* 平台数据（board 板级文件中） */
UART0_PLATFORM_DATA_BEGIN(uart0_data);
    .baudrate = 1000000,            /* 调试串口 1M */
    .tx_pin   = IO_PORT_DP,         /* 本机: DP/DM 复用作 TX/RX */
    .rx_pin   = IO_PORT_DM,
    .clk_src  = UART_CLK_SRC_PLL48M,
UART0_PLATFORM_END();

uart_init(&uart0_data);

/* 常用接口（include_lib/driver/device/uart.h） */
uart_send_data(&uart0_dev, buf, len);
uart_recv_data(&uart0_dev, buf, len);   /* 从环形缓冲取走数据 */

/* 典型调试口: printf 走 UART0 */
本机实践：充电头供电场景下 USB 会抢占 DP/DM，用「按住任意键上电」进入日志模式可禁用 OTG、把 DP/DM 让给 UART0 做全程日志。
