CHAPTER 17

其他外设

看门狗、脉冲计数、旋转解码、PWM 呼吸灯、并口/PDM/段码 LCD 等其余片上模块速览（基址 + 寄存器布局 + SDK API 指引）。

看门狗（RTC 域）

看门狗位于 RTC/RTC_WDT 中断域（IRQ 10），16 档超时 1ms-32s。SDK 启动即开启， 长循环里手动 wdt_clear()（本机目录扫描等长任务均有演示）。

#include "asm/wdt.h"
wdt_init(WDT_8S);        /* 或 WDT_1MS ... WDT_32S */
wdt_clear();             /* 喂狗 */
wdt_close();             /* 关闭（调试慎用） */
u32 ms = wdt_get_time(); /* 剩余毫秒 */

计数器类外设

外设基址寄存器用途
PCNT 脉冲计数0x1E1000CON / VAL外部脉冲计数
GPCNT 全局计数0x1E1100CON / NUM(RO)任意时钟源计数（CLK_CON1[6:4] 选源：OSC/PLL480M/IRFLT…）
LRCT 低功耗计数0x1E3600CON(WO) / NUM(RW)RTC 域低功耗定时
RDEC0-2 旋转解码0x1E2C00/4400/4500CON / DAT (u8)编码器 AB 相硬解码（音量旋钮）

PWM 呼吸灯（JL_PLED @ 0x1E5200）

硬件呼吸灯控制器：CON0-3 全局配置，BRI_PRDL/H（呼吸周期）、BRI_DUTY0/1 （呼吸占空）、PRD_DIVL + DUTY0-3（普通 PWM），CNT_RD（RO）读计数。 SDK 经 pwm_led.h API 配置。

偏移寄存器属性说明
0x00CON0-3RW模式/时钟/极性
0x10BRI_PRDL/HRW呼吸周期低/高
0x14BRI_DUTY0L/H / DUTY1L/HRW呼吸占空
0x28PRD_DIVLRW普通 PWM 周期分频
0x2CDUTY0-3RW普通 PWM 占空 ×4
0x3CCNT_RDRO计数器读出

其余模块速览

模块基址寄存器说明
MODE0x1E0100MODE_CON芯片工作模式
RST 源0x1E00C0SRC(RO)复位来源读出
SYSTEM0x1E0200CHIP_ID / MBIST_CON芯片 ID 与 RAM 自检
IR 滤波0x1E3200RFLT_CON红外接收滤波
OSA0x1E3400CON振荡/系统辅助
CTM 触摸0x1E3C00CON0/CON1/ADR内置电容触摸（本机用外挂 CST836U/I²C）
PAP 并口0x1E2800CON/DAT0/1/BUF/ADR/CNT8 位并口（摄像头/并口屏）
PLNK PDM0x1E2D00CON/SMR/ADR/LENPDM 麦克风链路
SS 同步串口0x1E2B00CON/SR_CNT/IO_CON/DMA…同步串行（含 SPDIF 用途）
LCD 偏压0x1E5300CON0/SEG_IOEN0/1段码 LCD 偏压与段 IO 使能
EFUSE0x1E3700CON / MEeFuse 读取（ChipKey 烧录校验）
以上寄存器布局来自 br23.h 结构体定义（成员即寄存器、每成员 4 字节）；除标注 u8/u16 访问的（RDEC/PERIENC/SD 部分）外均按 32 位访问。具体位定义 SDK 多数未公开——优先使用对应的 API 头文件。
