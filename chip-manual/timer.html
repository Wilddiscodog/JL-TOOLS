CHAPTER 8

定时器

4 组 32 位定时器：系统时基、周期中断与 TIMER-PWM 输出——对应 JL_TIMER0-3（0x1E0400 起）。

概述

4 个 32 位通用定时器（TIMER0-3），寄存器组仅 4 个：CON / CNT / PRD / PWM。 SDK 用其中之一维护系统 TICK（timer_get_ms()）， timer_pwm_init() 可把任意 TIMER 变成 PWM 输出通道（经 IO 输出通道映射到引脚）。 高频 PWM 需求应改用 MCPWM 外设（8 通道）。

图 8-1 定时器结构

寄存器（JL_TIMER0 @ 0x1E0400，TIMER1/2/3 = +0x100 递增）

偏移寄存器属性说明
0x00CONRW使能/时钟分频/计数模式（SDK 驱动管理）
0x04CNTRW当前计数值（可读写）
0x08PRDRW周期终值，CNT 计到 PRD 产生事件
0x0CPWMRWPWM 比较值/极性

使用方法

#include "asm/timer.h"
#include "asm/mcpwm.h"

/* 1. 系统时基（SDK 已自动启用） */
u32 now = timer_get_ms();
u32 sec = timer_get_sec();
delay_2ms(10);                       /* 阻塞延时（2ms 粒度） */

/* 2. OS 级软定时器（推荐，非阻塞） */
#include "system/timer.h"
sys_timer_add(NULL, my_tick_cb, 20);     /* 20ms 周期回调 */
sys_timeout_add(NULL, once_cb, 500);     /* 单次 */

/* 3. TIMERx 直接作 PWM 输出 */
timer_pwm_init(JL_TIMER0,               /* 定时器 */
               20000,                   /* 20kHz */
               500,                     /* 占空比 0-10000 */
               IO_PORTA_02,             /* 输出引脚 */
               CH0_T0_PWM_OUT);         /* IO 输出通道 */
set_timer_pwm_duty(JL_TIMER0, 2500);
实践建议：UI 刷新/按键扫描用 sys_timer_add（OS 软定时器），只有精确波形才占硬件 TIMER；软关机前记得 sys_timer_del 清理。
