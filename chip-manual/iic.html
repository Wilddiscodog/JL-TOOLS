CHAPTER 7

IIC 总线

硬件 I²C 主/从控制器：完整公开的位定义、START/STOP 硬件时序、滤波与从机时钟拉伸——对应 JL_IIC（0x1E2400）。

概述

1 路硬件 I²C（JL_IIC @ 0x1E2400），支持主机/从机、7 位寻址、 时钟拉伸与滤波。iic_hw.h 给出了完整的 CON0/CON1 位操作宏——这是全芯片 为数不多位定义完全公开的外设，可直接寄存器级编程。另有软件 I²C（iic_soft.h） 可用任意 GPIO 模拟。

寄存器（JL_IIC @ 0x1E2400）

偏移寄存器属性说明
0x00CON0RW主控寄存器（位定义见下）
0x04BUFRW数据寄存器
0x08BAUDWO波特率（SCL 频率分频）
0x0CCON1RW辅助控制（SI 模式/启动 pending）

CON0 位定义（来自 iic_hw.h 宏）

位域名称说明
[0]enable模块使能
[1]role0=主机，1=从机
[2]cfg_done配置生效触发
[3]dir0=输出，1=接收
[4]preset_end预置 STOP
[5]preset_restart预置重复 START
[6]recv_ack接收时应答：0=ACK，1=NACK
[7]send_is_ack（读）发送后收到 ACK 状态
[8]ie字节中断使能
[9]isel0=直通，1=滤波
[10]end_ie传输结束中断使能
[12]end_pnd_clr（写 1）清除结束 pending
[13]end_pnd（读）传输结束标志
[14]pnd_clr（写 1）清除字节 pending
[15]pnd（读）字节传输完成标志
位域名称说明
CON1[13]si_mode_en从机 SI 模式
CON1[15]start_pnd（读）检测到 START
CON1[14]start_pnd_clr（写 1）清除 START pending

使用方法

#include "asm/iic_hw.h"

/* 寄存器级（宏齐全，主机写示例） */
iic_disable(JL_IIC);
iic_role_host(JL_IIC);
iic_baud_reg(JL_IIC) = 200;         /* SCL 频率分频 */
iic_cfg_done(JL_IIC);
iic_enable(JL_IIC);

/* 发送器件地址+写 */
iic_dir_out(JL_IIC);
iic_buf_reg(JL_IIC) = dev_addr << 1;
while (!iic_pnd(JL_IIC));
iic_pnd_clr(JL_IIC);
if (!iic_send_is_ack(JL_IIC)) { /* NACK 处理 */ }

/* 推荐：SDK 设备层（软件 IIC 同接口，引脚自由） */
触摸屏 CST836U、各类传感器用软 I²C 更常见（引脚自由）；硬件 I²C 适合固定引脚的高速场景。
